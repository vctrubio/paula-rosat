# Relaciones: estampa de cítricos

La versión actual es `public/illustrations/relaciones.png`, con su copia WebP para la web. Se generó con imagegen tomando la estampa de cítricos facilitada por el usuario como referencia de detalle y la ilustración anterior como referencia de composición.

Dos rodajas conectadas por un tallo con hojas, tinta ocre, bordes irregulares, marcas talladas en la pulpa, nervaduras y textura de impresión. Fondo transparente.

`public/illustrations/relaciones.svg` y `docs/artwork/relaciones-mark.svg` conservan la versión vectorial anterior; no son la fuente de la imagen actual. La aplicación carga `relaciones.webp` mediante `illustrationSource`.
