# Paula Rosat

Paula Rosat’s illustrated botanical portfolio, built with Next.js App Router, React, TypeScript, Tailwind CSS and next-intl.

## Working on the project

Read `AGENTS.md` and the relevant installed Next.js documentation before changing framework code. Keep page files as component compositions. Preserve the botanical artwork and restrained Cormorant Garamond / DM Sans typography. `/dev` is a separate development-only brand notebook; public-page changes should not alter its specimens.

## Public page

`src/app/page.tsx` composes About, Map, Process and the closing footer. The ecosystem components are retained for future use but are currently excluded from the public page.

- About: curved name, illustrated portrait, animated bio and circular language selector.
- Map: illustrated relationships with links to the corresponding process steps.
- Process: blackberry and juniper sorbet example.
- Footer: closing illustration, contact links and sharing.

Story panels and the footer are centered and capped at 80rem (`max-w-7xl`). The navbar spans the viewport while its content follows the same edges; beyond 80rem its background becomes translucent. Shared sizing variables live in `src/app/globals.css`.

## Languages and editable text

The site supports **ES → EN → CA → FR**, with Spanish as the default. All public copy lives in `text/{es,en,ca,fr}/`, split by section. See [text/README.md](text/README.md) for the structure and editing rules.

`src/i18n/config.ts` defines the locales. `src/i18n/request.ts` loads the chosen catalog, and `src/i18n/actions.ts` saves a validated selection in the `paula-locale` cookie for a year. Switching rerenders the current page without changing its URL. The selected label is bold and the tiny still’s spout rotates towards it. The circle fades with the portrait while scrolling.

Public text, metadata, image descriptions, diagram labels, contact labels and sharing feedback follow the selected language. The shared PNG card remains Spanish; its source wording comes from `text/es/metadata.json`. Development specimens and editorial documentation retain their source languages.

## Scrolling

`src/components/story-journey.tsx` owns navigation, chapter progress, portrait erasure and sheet measurements. A ResizeObserver measures each sheet: tall chapters scroll fully before pinning at the viewport bottom. Do not replace this with `top: 0` for every sheet or put overflow/transforms on scroll ancestors. Navigation uses flow offsets, rather than sticky rectangles, to return to chapter beginnings.

The navbar appears as the portrait name disappears. Its Instagram action changes to a back-to-top control when the footer enters. Short windows and reduced-motion preferences use ordinary section flow; reduced motion also disables smooth scrolling and pointer transitions.

## Repository structure

- `text/`: all public wording, grouped by locale and section.
- `src/components/sections/`: public chapter compositions.
- `src/components/map/`: diagram, artwork and process rendering.
- `src/content/map-layout.ts`: stable artwork IDs, coordinates and structural types.
- `src/content/artwork-assets.ts`: image preload inventory.
- `src/config/`: site contact information, brand geometry and sharing-image configuration.
- `src/components/dev/`: development notebook and specimens.
- `public/`: published artwork, portrait and generated sharing images.
- `docs/` and `MAP.md`: artwork references and editorial/design documentation.

## Development

```sh
npm install
npm run dev
npm run lint
npx tsc --noEmit
npm run text:check
npm run build
```

`/dev` returns 404 outside development and carries noindex metadata. Fonts use `next/font/google`; an initial build may need network access.

## Hosting and sharing

Production: `https://paularosat.com`, hosted on Vercel with the domain managed through GoDaddy. `src/config/seo.ts` owns the production URL and image configuration. The request locale determines descriptions and metadata in `src/app/page.tsx` and `src/app/layout.tsx`.

The 1200 × 630 sharing card is generated by `scripts/seo-card.tsx` with bundled Cormorant Garamond. Run `npm run seo:images` after changing its design or source wording. The favicon is `public/icon.png`.

Sharing uses native sharing when available, then clipboard copying, then a manual-copy fallback. External services need a deployment before they can read changed metadata or images.
